# 🎟️ Ticket Booking App

A full-stack ticket booking application where users can register, log in, and book event tickets seamlessly. This project uses a **Node.js + Express** backend and a **React.js** frontend.

---

## 🛠️ Tech Stack

### Frontend
- **React.js**
- **Vite**
- **Tailwind CSS**
- **Axios** for API calls
- **Vercel** for deployment

### Backend
- **Node.js**
- **Express.js**
- **MongoDB** with Mongoose
- **JWT Authentication**
- **CORS & dotenv**
- **Render** for deployment
